01 Resumen ejecutivo

Qué es Wikilinks

Wikilinks es una aplicación web personal orientada a resolver el desorden generado por enlaces guardados sin criterio: vídeos de YouTube, artículos, herramientas, recursos, páginas web, ideas y contenidos que pueden ser útiles, pero que suelen terminar perdidos en “Ver más tarde”, WhatsApp, pestañas abiertas o listas poco accionables.

La evolución actual del proyecto supera el alcance inicial de Wikilinks Video Hub. La app ya no se limita a organizar vídeos: incorpora un segundo módulo para enlaces web, un sistema de acciones/tareas, categorización, etiquetas, prioridades, estados, búsqueda global y preparación de contenidos para Notion.

Idea central: no se trata de guardar más enlaces, sino de decidir qué hacer con ellos: ver, leer, descartar, convertir en acción o guardar como referencia.

02 Problema y oportunidad

Problema de partida

  • Se guardan vídeos de YouTube sin un sistema claro de consumo.
  • Los enlaces útiles acaban mezclados con ocio, formación, herramientas, podcasts o artículos.
  • Las listas nativas de YouTube o los mensajes enviados a una misma persona no ayudan a decidir qué hacer después.
  • No existe un flujo claro para pasar de contenido guardado a acción, referencia o descarte.
  • Notion no debe llenarse de enlaces basura: solo deben llegar los recursos realmente útiles.

Oportunidad de producto

Wikilinks actúa como una capa intermedia entre el consumo impulsivo de contenido y la gestión seria del conocimiento personal.

05 IA y metadatos

Metadatos de YouTube

Cuando se añade un vídeo, la app extrae el ID de YouTube y consulta la API para recuperar título, canal, miniatura/carátula, duración y fecha de publicación. Si la API falla, usa oEmbed como fallback.

  • Formatos soportados: youtube.com/watch, youtu.be y shorts.
  • La miniatura puede cargarse desde YouTube Data API o mediante URL estándar de imagen del vídeo.
  • La duración ISO 8601 se convierte a segundos para filtros y visualización.

Resumen / análisis IA

En la ficha del vídeo existe un bloque de Resumen IA con botón para generar análisis, estado de carga, reintento y regeneración.

Uso responsable de IA

La IA se usa como apoyo de decisión y reducción de fricción, no como sustituto de criterio. El usuario sigue decidiendo si el recurso se ve, se descarta, se convierte en acción o se guarda en Notion.

06 Funcionalidad de acciones

Qué resuelve

La función de acciones evita que Wikilinks sea solo un almacén bonito. Permite convertir un contenido en una tarea concreta: probar una herramienta, revisar un tutorial, aplicar una técnica, investigar una idea, preparar un post o guardar una referencia.

  • Vista propia de acciones.
  • Creación manual de nuevas acciones.
  • Estados: pendiente y completada.
  • Acciones vinculadas a vídeos mediante video_id.
  • Acciones vinculadas también a enlaces web mediante web_link_id.

12 Defensa del proyecto

Argumento principal

Wikilinks demuestra cómo una necesidad personal muy concreta puede transformarse en un producto digital funcional: una aplicación que ordena el caos de enlaces y vídeos guardados, reduce la fricción de captura, añade automatización útil y permite convertir información dispersa en conocimiento y acciones.

El valor del proyecto no está solo en la tecnología, sino en el diseño del flujo: guardar menos basura, clasificar mejor, decidir antes y actuar después.

Frase de cierre

Wikilinks no es una app para acumular enlaces. Es una herramienta para convertir contenido guardado en decisiones, conocimiento y acciones.

13 Objetivos y alcance

Objetivo general

Diseñar y desarrollar una aplicación web funcional que permita capturar, ordenar y revisar recursos digitales de forma consciente. Wikilinks busca transformar vídeos y enlaces dispersos en una biblioteca personal útil, accionable y conectada con herramientas externas como Notion.

Objetivos específicos

  • Crear un sistema de alta rápida para vídeos de YouTube y enlaces web.
  • Automatizar la captura de metadatos para reducir fricción.
  • Permitir clasificación mediante categorías, etiquetas, prioridad y estado.
  • Incorporar acciones/tareas vinculadas a recursos.
  • Preparar recursos seleccionados para exportación a Notion.
  • Ofrecer una experiencia móvil instalable mediante PWA.

Dentro del alcance

  • Aplicación privada con login de Google.
  • Módulos de vídeos, webs, acciones, búsqueda, Notion y ajustes.
  • Persistencia de datos por usuario en Supabase.
  • Despliegue público protegido en wikilinks.liagil.es.
  • Documentación técnica mediante README y memoria HTML.

Fuera del alcance actual

  • Red social o biblioteca compartida entre usuarios.
  • Transcripción completa de vídeos de YouTube.
  • Recomendaciones automáticas avanzadas basadas en historial.
  • Sincronización bidireccional completa con Notion.
  • Aplicaciones nativas para iOS o Android.

16 Metodología de desarrollo e IA

Desarrollo asistido por IA

El proyecto se ha construido combinando criterio humano, desarrollo iterativo y apoyo de herramientas de IA. La IA se ha usado para acelerar análisis, generación de código, revisión de errores, documentación y mejora de la memoria, pero las decisiones de producto, alcance y validación se han mantenido bajo dirección humana.

El enfoque seguido puede describirse como un proceso de vibe coding supervisado: se parte de una necesidad concreta, se describe el comportamiento esperado, se implementa, se prueba y se ajusta según los resultados reales de la app.

Rol humano

  • Definir el problema y la utilidad real.
  • Validar si una función aporta valor.
  • Comprobar el estado real de GitHub y despliegue.
  • Revisar la memoria y decidir tono de entrega.

17 Construcción técnica

Frontend y rutas

La aplicación usa Next.js 14 con App Router. Las rutas privadas se agrupan bajo src/app/(app), con páginas específicas para inicio, webs, detalle de vídeo, detalle web, acciones, ajustes, historial, papelera, etiquetas, categorías y Notion.

Estado global y datos

Zustand centraliza vídeos, enlaces, acciones, categorías, prioridades, etiquetas, tema, tamaño de texto y configuración de Notion. Supabase actúa como persistencia por usuario, con políticas RLS para aislar datos.

APIs internas

  • /api/youtube: obtiene metadatos de YouTube.
  • /api/summarize: genera resumen con Gemini.
  • /api/opengraph: intenta enriquecer enlaces web.
  • /api/notion: crea páginas en Notion.
  • /api/keepalive: mantiene activo Supabase mediante consulta ligera.

Despliegue

El proyecto incluye Dockerfile, Docker Compose y workflow de GitHub Actions. El flujo de despliegue previsto actualiza el código en el VPS desde main y reconstruye el contenedor.

20 Privacidad e IA responsable

Privacidad

Wikilinks usa autenticación con Google mediante Supabase Auth. Cada usuario accede a sus propios recursos y ajustes. La documentación no incluye claves, tokens ni valores de archivos .env.

  • Datos asociados al usuario autenticado.
  • Variables sensibles fuera del repositorio.
  • Repo compartido con el profesor mediante invitación.

Uso responsable de IA

La IA se usa como apoyo para resumir o analizar, pero el usuario conserva la decisión final. La app no debe presentar el análisis como verdad absoluta, sino como ayuda para priorizar y decidir.

  • El resumen ayuda a decidir, no sustituye la revisión.
  • El usuario marca estados y candidatos a Notion.
  • Las acciones siguen siendo creadas y validadas por la persona.

22 QA, backlog y limitaciones

Checklist de pruebas

  • Login con cuenta Google.
  • Añadir vídeo de YouTube y obtener metadatos.
  • Detectar vídeo duplicado.
  • Añadir enlace web y clasificarlo.
  • Crear acción vinculada a vídeo y web.
  • Buscar recurso desde búsqueda global.
  • Marcar recurso como candidato a Notion.
  • Probar vista móvil/PWA y compartir enlace.

Limitaciones actuales

  • Resumen IA sin transcripción completa del vídeo.
  • La app pública requiere login para revisar módulos internos.
  • OpenGraph puede ser parcial según la web de origen.
  • La vista global de acciones puede mejorar el contexto de enlaces web.
  • No existe todavía modo demo público con datos ficticios.
